# ライター向けフィードバック指示書
## 占術家 時雨（shigure_fortune）Threads 次バッチ用

## 1. 積極的に使うべきパターン・テーマ

**【パターン】**

- **`kotodama_rank`（平均スコア 92.3 — 最高値）**
  → 全パターン中ダントツ1位。ランキング形式の言霊投稿は最優先で量産する
- **`daily_energy`（平均 70.3）**
  → 日々の気・エネルギー系コンテンツ。継続して安定エンゲージを稼げる柱
- **`list`（平均 54.0）**
  → リスト形式は読了率・保存率が高い。行動を促すリストとして設計する
- **`harm_revelation`（平均 27.6）**
  → スコアにばらつきはあるが、**54点の高火力実績あり**（牡羊座投稿）。書き方次第で跳ねる

**【テーマ】**

- **「暮らしの吉方位と気の整え方 / ランチ・カフェで吉方位活用」（平均 239.5 — 1位）**
  → 圧倒的トップ。日常生活に落とし込んだ吉方位コンテンツを毎バッチ必ず複数本入れる
- **「方位の基礎知識 / 方位の吉凶が決まる仕組み」（平均 145.25）**
  → 教育系コンテンツとして安定。新規フォロワー獲得にも効く。定期的に入れる
- **「開運日 / 天一天上と吉方位」（平均 111.5）**
  → タイムリー性が高くシェアされやすい。投稿タイミングを実際の開運日に合わせる
- **「鑑定エピソード / 停滞から動き出した人の共通点」（平均 84.0）**
  → ストーリー型で鑑定導線につながりやすい。CVR向上に直結するため優先継続

## 2. 控えるべきパターン・テーマ

**【テーマ】**

- **「転機のサイン / 動けない本当の理由」（平均 4.0）**
  → 刺さるはずのテーマだがスコアが最低水準。切り口を大幅に変えるか、しばらく休止
- **「引き寄せ / 願いを叶える方位」（平均 4.0）**
  → 「引き寄せ」はトップテーマでも機能しているが、この切り口は不発。サブテーマを変えて再検証
- **「神社・パワースポット / 神社参拝と開運」（平均 4.0）**
  → 時雨のブランド（吉方位・龍脈命術）とのズレがある可能性。当面は優先度を下げる

**【パターン】**

- **`zodiac_ranking`（直近 5点）`zodiac_target` `client_voice`（直近 4〜7点）**
  → 星座系でも`harm_revelation`や`caligula`（38点）は機能している。単純な「星座＋ランキング」「星座＋悩み共感」の組み合わせは飽和気味。リニューアル必要
