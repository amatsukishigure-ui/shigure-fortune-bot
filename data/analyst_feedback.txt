# ライター向けフィードバック指示書
## 占術家 時雨（shigure_fortune）次バッチ用

---

## 1. 積極的に使うべきパターン・テーマ

### ✅ パターン

- **`kotodama_rank`（スコア70.8）** → 全パターン中ダントツ1位。言霊・断言系の短文構成は必ず各バッチに複数本含める
- **`harm_revelation`（スコア38.7）** → 「なぜうまくいかないのか」を暴く構成。共感→解説→方位/命術への橋渡しが鉄板
- **`zodiac_target`（直近スコア52.0）** → 星座を絞って話しかける構成。直近最高スコアを記録。1バッチに3〜4本は入れる
- **`card_pick`（スコア34.0）** → 参加型・選ばせる形式。エンゲージメント（返信・リポスト）を稼ぎやすい

### ✅ テーマ

- **「吉方位・風水 / 金運アップの吉方位」（スコア325.8）** → 他テーマを圧倒する断トツ1位。毎バッチ最低2〜3本確保。金運ワードは鉄板
- **「転機のサイン / 転換点を龍脈命術で見ると」（スコア82.3）** → 転職・引越し層に直撃。CTAとの相性も高い
- **「鑑定エピソード / 人生の転機になった鑑定」（スコア80.0）** → 実話ベースの語り口は信頼感を高め、サービス誘導への自然な導線になる
- **「今日の吉方位」（スコア57.7）** → デイリーコンテンツとして定期配置。習慣読者を獲得しやすい

## 2. 控えるべきパターン・テーマ

### ❌ テーマ

- **「星座占い / 今週の運気（全体）」（スコア2.95）** → 星座を絞らない"全体向け"運気投稿は完全に埋もれる。全体向けは廃止、必ず星座指定に変換する
- **「季節・天文と方位 / 春分・秋分と方位」（スコア3.89）** → 知識寄りすぎて「自分ごと」にならない。投稿するなら「春分にこの方位へ動いた人が変わった」など体験談に変換してから使う
- **「暮らしの吉方位 / 玄関の気の整え方」（スコア4.48）** → 直近でも蟹座に絞った構成でスコア4.48止まり。単体テーマとしては当面封印。どうしても使う場合は`harm_revelation`型（「玄関を整えない人が逃している運気」）に変換する

### ❌ パターン注意

- **`client_voice`（直近スコア7.4 / 6.3）** → お客様の声・証言系は単体で機能していない。必ず「転機のサイン」「金運」などスコア上位テーマと組み合わせること。単品のお声紹介投稿は次バッチでは作らない
- **`zodiac_ranking`（直近スコア6.3）** → ランキング形式の
