# ライター向けフィードバック指示書
**アカウント：占術家 時雨 / 次回バッチ用**

---

## 1. 積極的に使うべきパターン・テーマ

**【パターン】**

- **`kotodama_rank`（スコア98.9）← 最優先**
　→ 全パターン中ダントツ1位。このアカウントの核。必ず毎バッチ複数本含めること
- **`lucky_combo`（スコア40.5）**
　→ 2位。「組み合わせで効く」という情報設計が刺さっている。龍脈命術の複合性と相性が良い
- **`caligula`（スコア34.0）**
　→「知りたくなる・見たくなる」禁断感の演出が機能している。続けて使う価値あり
- **`harm_revelation`（スコア29.2）**
　→ 直近でも水瓶座の投稿が66点を記録。「有料鑑定でしか話していないことを」の型が引きを生んでいる。積極採用

**【テーマ】**

- **「時雨の世界観 / 停滞している人に言い続けてきたこと」（スコア169）← 最優先**
　→ 圧倒的1位。時雨自身の言葉・信念を前面に出す投稿がもっとも響いている
- **「方位の基礎知識 / 方位の吉凶が決まる仕組み」（スコア152）**
　→ 教育系コンテンツとして機能。「なぜ吉方位が効くのか」の理由説明を丁寧に
- **「吉方位・風水 / 今日の吉方位」（スコア102）**
　→ 定期的に回すことで習慣的フォロワーを育てられる。継続必須
- **「運気 / 運気が上がるタイミング」「転機のサイン / 同じ悩みを繰り返す人の方位的な原因」**
　→ どちらもターゲット（岐路に立っている人）の痛みに直撃するテーマ

## 2. 控えるべきパターン・テーマ

**【テーマ】**

- **「星座占い / 今月の運気まとめ」（スコア2.0）← 最も低調**
　→ 一般的な星座占いとの差別化ができていない。「まとめ」型は埋もれる。廃止または大幅改変
- **「転機のサイン / 動けない本当の理由」（スコア4.0）**
　→ タイトルが抽象的すぎる。読者が「自分ごと」にできていない可能性。テーマ自体は良いので、切り口を変えて再挑戦
- **「吉方位・風水 / 凶方位の対処法」（スコア4.0）**
　→「対処法」という実用ワードが時雨の神秘的トーンと合っていない。「凶方位にいると起きること」など感覚寄りに変換して試す

**【パターン】**

- **`card_pick`** は直近3本のうちスコアが1〜17点とバラつき大
　→ 単体では弱い。`harm_revelation`や`kotodama_rank`と組み合わせるか、しばらく頻度を落とす
