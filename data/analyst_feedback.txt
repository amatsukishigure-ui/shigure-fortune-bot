## 1. 積極的に使うべきパターン・テーマ

### ✅ パターン

- **`kotodama_rank`（スコア平均70.8）**
  → 全パターン中ダントツ1位。「ランキング形式」や「対比構造」で真理を断言するパターン。最優先で使うこと。
- **`caligula`**
  → 直近で33.7のスコアを記録。「〜な人にこそ聞いてほしい」の逆張り構造は引きが強い。積極採用。
- **`zodiac_target`（直近52.0）**
  → 星座を絞り込み、特定の悩み状態に語りかける型。ターゲットが「自分のことだ」と感じる設計が効いている。
- **`ichi_gon`（スコア平均29.5）**
  → 一言の断言＋補足展開。時雨のトーン（静かな確信）と相性が良い。

### ✅ テーマ

- **「吉方位・風水 / 金運アップの吉方位」（スコア325.8）**
  → 圧倒的首位。金運×吉方位の組み合わせを毎バッチ最低2〜3本は必ず入れること。
- **「転機のサイン / 転換点を龍脈命術で見ると」（82.3）**
  → 転職・引越し迷い層に直撃するテーマ。ターゲット層のペインに最も刺さる。
- **「鑑定エピソード / 人生の転機になった鑑定」（80.0）**
  → 実績の裏付けとして機能。実際に動いた話・変わった話を具体的に。
- **「時雨の世界観 / なぜ方位にたどり着いたか」（73.3）**
  → 自己開示系は信頼構築に直結。直近でも73.3を記録。バッチに1本は入れること。
- **「星座別メッセージ / 今週の星座別メッセージ」（62.0）**
  → 星座系は安定した集客コンテンツ。ただし「全体運」ではなく特定星座に絞ること。

## 2. 控えるべきパターン・テーマ

### ❌ テーマ

- **「星座占い / 今週の運気（全体）」（スコア2.95）**
  → 全体向けは刺さらない。「全星座に向けた今週の運勢」は廃止。星座を必ず絞ること。
- **「季節・天文と方位 / 春分・秋分と方位」（3.89）**
  → 季節イベント×方位は反応薄い。タイムリー感より悩みへの直撃を優先。
- **「暮らしの吉方位と気の整え方 / 玄関の気の整え方」（4.48）**
  → 生活Tips系は低調。直近でも4.5止まり。このカテゴリは原則ストップ。

### ❌ 注意すべきパターン

- **`zodiac_ranking`**
  → 直近で6.3と73.3に二極化。テーマ次第
