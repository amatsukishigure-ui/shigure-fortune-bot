# ライター向けフィードバック指示書
**アカウント：占術家 時雨 ／ 次回バッチ用**

## 1. 積極的に使うべきパターン・テーマ

**パターン**

- **`kotodama_rank`（言霊ランキング）** → スコア83点・55点と安定して高い。「ランキング形式」が好奇心とスクロール停止を同時に誘発している。週1以上で継続投入すること
- **`caligula`（カリギュラ効果）** → 蟹座投稿がスコア220点（直近最高）。「〇〇な人だけ読んで」「〇〇以外は読まなくていい」の限定排除フォーマットは必ずキープ
- **`client_voice`（クライアントの声）** → 全パターン中スコア100点でトップ。信頼構築に直結。バッチに最低2本は入れる
- **`ritual_action`（儀式的行動）** → スコア67点台で安定。「今夜やること」「明日の朝やること」など時間を限定する行動指示が鍵

**テーマ**

- **「龍脈命術の世界観／停滞の意味」** → スコア235点で全テーマ1位。"停滞・空回り・なんか違う"という感覚に刺さっている。このテーマを軸に複数展開する
- **「方位の基礎知識／九星気学の基本」** → スコア183点。難しそうな概念を"知らなかった側の視点"から解説する投稿が伸びている
- **「運気／総合運」** → スコア160点。蟹座・山羊座など星座を絞ってターゲティングすると効果倍増

## 2. 控えるべきパターン・テーマ

**パターン**

- **`before_after`** → 直近スコア1.47点と最低。「変化の比較」を論理的に見せようとすると時雨の世界観（神秘・確信）と温度感が合わなくなる。当面使用禁止
- **`hoshi_betsu`（星座別まとめ系）** → スコア6.97点。「全星座まとめ」系は薄く見える。星座を絞った`caligula`型に切り替えること
- **`zodiac_target`** → スコア17点台。使えなくはないが、単体では弱い。`caligula`と組み合わせてのみ使用する

**テーマ**

- **「風水豆知識／色と方位・玄関」** → スコア0.0点。情報提供型の豆知識は完全に沈黙している。「知識を教える投稿」ではなく「気づきを与える投稿」に変換する必要がある
- **「吉方位の調べ方（初心者）」** → 同じくスコア0.0点。ハウツー説明型は時雨のトーン（断言・確信系）と相性が悪い。廃止または「あなたは今まで調べ方を間違えていた」型に変換する
- **「星座占い／今週の運気（全体）」** → スコア1.47点。"全員向け今週の運気"は競合が多く差別化できない。必ず星座を1つに絞るかcaligula型にする
