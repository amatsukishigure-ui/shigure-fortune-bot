# ライター向けフィードバック指示書
## 占術家 時雨（shigure_fortune）次バッチ用

---

## 1. 積極的に使うべきパターン・テーマ

### 【パターン】

- **`ritual_action`（スコア67.7）**
  → 「今日やること」「今夜試して」など、即行動に結びつく具体的な開運アクションを提示する型。読者の保存・シェア動機が高い。毎バッチ3〜4本は確保すること。

- **`client_voice`（スコア66.3）**
  → 鑑定を受けた人のビフォーアフターや実感を語る型。信頼性と共感が同時に取れる。「〜さんは、こう変わった」「鑑定後、こんな連絡が来た」形式で書く。

- **`soft_discovery`（スコア53.6）**
  → 「実は知らなかった」「これ、常識と逆でした」など、軽い驚きを入口にする発見型。押しつけがましくなく拡散されやすい。

- **`caligula`（直近スコア36.1・17.7）**
  → 「〜な人以外は読まなくていい」で始まるカリギュラ効果型。直近データでも高パフォーマンス。水瓶座・牡牛座の例が機能している。積極採用。

### 【テーマ】

- **「龍脈命術の世界観 / 停滞の意味」（スコア235）**
  → 断トツ1位。「今、なんか止まってる気がする」という感覚は読者の普遍的な悩み。停滞・詰まり・変われない、というキーワードを絡めたテーマを優先的に増やす。

- **「開運行動 / 健康運アップ」「方位の基礎知識 / 九星気学」（スコア183）**
  → 実用性が高く保存されやすい。「今すぐできること」として出口を明確にする。

- **「引き寄せ / 言葉と気の流れ」（スコア137）**
  → 龍脈命術の世界観と接続しやすく、ファン化に貢献するテーマ。「言葉の使い方で気は変わる」系の投稿を継続。

## 2. 控えるべきパターン・テーマ

### 【テーマ】

- **「季節・天文と方位 / 夏至・二十四節気」（スコア0.0）**
  → タイムリーに見えるが、完全にスベっている。暦ネタ単体では読者の当事者意識が薄い。「夏至だから〜しよう」ではなく、「今、あなたの気が動いている理由」という自分ごと化が必要。単発では使わない。

- **「星座占い / 恋愛運」（スコア0.0）**
  → 汎用的すぎて時雨の世界観との差別化ができていない。一般的な「〇〇座の恋愛運」は埋もれる。使うなら龍脈命術・方位・気の流れと必ず接続すること。単体投稿は禁止。
