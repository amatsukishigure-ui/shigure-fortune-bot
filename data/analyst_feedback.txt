## 1. 積極的に使うべきパターン・テーマ

**パターン**

- **`kotodama_rank`（スコア95）**　→　最高スコア。「ただ眺めてるだけで終わってない？」のように、読者の"受け身な行動"を指摘してから価値を示す流れが刺さっている。毎バッチ最低3本は入れる
- **`weekly_forecast`（スコア57）**　→　安定した数字。時期性・緊急性が出やすく、エンゲージを底上げする。週次で1〜2本確保する
- **`harm_revelation`（スコア43）**　→　「実は損してる」「勘違いしてた」系。読者の思い込みを崩す切り口が機能している
- **`card_pick`**　→　直近の獅子座モニター誘導でスコア53。「A・B・Cどれに近い？」形式が返信・保存を誘発しやすい。メニュー誘導に組み合わせると◎

**テーマ**

- **「吉方位・風水 / 金運アップの吉方位」（スコア325）**　→　圧倒的1位。このテーマは惜しまず量を出す。週2本ペースでも消耗しない
- **「吉方位・風水 / 恋愛・結婚の吉方位」（スコア172）**　→　同カテゴリの恋愛文脈も高反応。金運・恋愛を交互に回す設計でOK
- **「引き寄せ / 感謝と運気の関係」（スコア94）**　→　精神的なテーマだが数字が出ている。龍脈命術の「気の流れ」と紐づけると世界観を損なわず書ける
- **「鑑定エピソード / 人生の転機になった鑑定」（スコア80）**　→　信頼構築とCTA誘導の両方に使える。バッチに1本は確保する

## 2. 控えるべきパターン・テーマ

**テーマ**

- **「龍脈命術と他の占いの違い」（スコア6.7）**　→　自己説明・メソッド解説系は読者に刺さらない。「違いを語る」より「動いた結果を見せる」に切り替える
- **「転機が近い時に起きること」（スコア6.9）**　→　抽象度が高すぎる。「転機のサイン」は直近10件でも低調。書くなら必ず具体的な現象（「急に連絡が来る」「眠れない夜が続く」等）に落とす
- **「星座別・気をつけること」（スコア7.3）**　→　「気をつけること」という後ろ向きの切り口が弱い。同じ星座別でも「今週やるべきこと」「今の気の向き」など前向き・行動系に言い換える

**パターン**

- **`fuusui_tip`単体**　→　直近スコア11.5。風水Tipsだけで終わると保存どまり。必ず「だからあなたは今〇〇すべき」という行動指示か、鑑定導線を末尾に入
