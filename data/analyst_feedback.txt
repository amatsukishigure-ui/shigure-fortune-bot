# ライター向けフィードバック指示書
**アカウント：占術家 時雨 / 次バッチ用**

## 1. 積極的に使うべきパターン・テーマ

**パターン**

- **`harm_revelation`（禁断開示型）** → 平均29点、直近で66点・20点を記録。最優先で使うこと
  - 「有料鑑定でしか話していないことを、今夜だけ出す」という構造が時雨のキャラクターと完全に一致している
  - 毎バッチ最低3本は組み込む

- **`zodiac_deep`（星座深掘り型）** → 平均27点、直近33点。zodiac_targetより大幅に優秀
  - 「龍脈命術で見ると、今の〇〇座には〜」という独自メソッドの言葉を必ず入れる
  - 「今週末だけ」「今夜だけ」の限定フレーズが機能している

- **`kotodama_rank`** → 平均89点と全パターン中ダントツ1位。本数を増やす価値あり

- **`lucky_combo`** → 平均40点で安定2位。定期的に差し込む

**テーマ**

- **「時雨の世界観 / 停滞している人に言い続けてきたこと」**（平均169点）→ 最強テーマ。毎バッチ必須
- **「方位の基礎知識 / 方位の吉凶が決まる仕組み」**（平均152点）→ 教育系でもこれは強い
- **「転機のサイン / 転機が近い時に起きること」**（平均120点）→ ターゲットの不安に直撃するテーマ

## 2. 控えるべきパターン・テーマ

**パターン**

- **`menu_guide`** → 直近2本がスコア4点・5点と低迷。サービス紹介を前面に出す投稿は今は機能していない。CTAは末尾に自然に添える程度に留める
- **`zodiac_target`** → 直近1点。星座を絞るだけでは届かない。`zodiac_deep`に置き換えること

**テーマ**

- **「星座占い / 今月の運気まとめ」**（平均2点）→ 汎用的すぎて時雨の差別化ができていない。廃止推奨
- **「転機のサイン / 動けない本当の理由」**（平均4点）→ タイトルが抽象的すぎる。「動けない本当の理由」は誰でも書けるコピーなので時雨らしさが消えている
- **「吉方位・風水 / 凶方位の対処法」**（平均4点）→ ネガティブワード（凶）を主役にした投稿は伸びない傾向。吉の文脈で語り直すこと
