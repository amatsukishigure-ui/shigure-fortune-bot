# ライター向けフィードバック指示書
## アカウント：占術家 時雨｜次バッチ制作指示

## 1. 積極的に使うべきパターン・テーマ

**◎ パターン**

- **`zodiac_deep`（平均53.7）** → 最高スコア。特定星座に深く刺さる1対1の語りかけ型。毎バッチ最低3〜4本は必ず入れる
- **`zodiac_ranking`（平均52.8）** → 「今週流れが変わる星座ランキング」形式。スクロールを止める視覚的構造が強い。週次コンテンツとして安定活用
- **`lucky_combo`（直近29pt）** → データ上位5位外だが直近で高スコア。「頑張っても流れが変わらない人へ」型の共感→龍脈命術紹介の流れが機能している。次バッチで意図的に増やす

**◎ テーマ**

- **「転機のサイン／停滞が続く人の共通点」（132.25）** → 断トツ1位。「動けない」「ループしている」という読者の自己認識に直撃する。毎バッチ必須
- **「転機のサイン／動けない本当の理由」（121.25）** → 上記と同系統。「意志の問題じゃない、向きの問題だ」の型と相性最良
- **「星座別メッセージ／今月の星座別メッセージ」（125.3）** → zodiac系パターンと組み合わせて安定量産できる
- **「方位の基礎知識／九星気学の基本」（106.5）** → 教育コンテンツとして機能。信頼構築＋フォロワー獲得に効く
- **「龍脈命術の世界観／龍脈命術と西洋占星術の違い」（97.0）** → 差別化投稿として認知拡大に貢献。ブランド投稿として定期的に挿入する

## 2. 控えるべきパターン・テーマ

**△ パターン**

- **`coconala_monitor`（直近5pt・6pt）** → サービス誘導が前面に出すぎてエンゲージが落ちている。CTAをいきなり出すのではなく、`zodiac_deep`や`lucky_combo`で共感を取り切ってから末尾に自然に添える形に変更する
- **`caligula`（直近10pt）** → 「〜以外は読まなくていい」の排除型フックは、単体では刺さりが弱い。`zodiac_deep`の冒頭に1行として仕込む補助的な使い方に留める
- **`daily_energy`（直近3pt）** → 週次エネルギー速報型。競合が多く差別化が薄れている。量を絞り、龍脈命術の視点を明確に入れた場合のみ使用

**△ テーマ**

- **「時雨の世界観／鑑定で一番多い相談と、時雨の答え」（1.0）** → 自己開示・内輪目線が強すぎる。読者のベネフィットを前面に出すフレームに書き直さない限り封印
- **「季節・天文と方位／上弦・下弦の月の使い方」（2.0）** → 情報提供
