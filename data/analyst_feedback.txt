## 1. 積極的に使うべきパターン・テーマ

**【パターン】**

- **`caligula`（カリギュラ効果型）** → 直近10件で最高スコア（39.9、27.7、19.5）を連発。「読まないほうがいい」「〇〇な人以外は読まなくていい」の構文は最優先で使う
- **`client_voice`（クライアントの声）** → スコア100.0で全パターン中1位。毎バッチ必ず1〜2本は入れること
- **`ritual_action`（儀式・行動提案）** → スコア67.7と高安定。「〜してみて」「〜をやめて」など具体的な行動指示で締める投稿

**【テーマ】**

- **「龍脈命術の世界観 / 停滞の意味」** → スコア235と群を抜いてトップ。「なぜ今動けないのか」「この停滞には意味がある」系の切り口を増やす
- **「開運行動 / 健康運アップ」「方位の基礎知識 / 九星気学の基本」** → 同率183と高水準。知識提供系でも教育的すぎず、行動につなげる構成にする
- **「龍脈命術の世界観 / なぜ方位を変えるだけで結果が変わるのか」** → 122と好調。時雨の独自メソッドを説明するテーマは引き続き継続

## 2. 控えるべきパターン・テーマ

**【テーマ】**

- **「星座別メッセージ / 気をつけること」「今月の星座別メッセージ」** → スコア0.0。星座別の横断一覧型は刺さらない。「全星座まとめて紹介」は原則NG
- **「季節・天文 / 水星逆行と吉方位」** → スコア0.0。天文イベントとの掛け合わせは現状ウケていない。使うなら必ずカリギュラ型フックとセットにする

**【注意点】**

- **`world_view`（世界観語り）** → スコア3.8と低調。時雨の哲学・信念を語るだけの投稿は単体で出さない。必ず「読者の今の状況」に紐づけてから世界観を語ること
- **`before_sleep`（就寝前行動）** → スコア8.5と低め。time系の切り口は「今夜〜」より「今この瞬間〜」の方が機能しやすい傾向あり

## 3. 直近バズり投稿から学んだ「型」の説明

### ✅ 最強型：**カリギュラ＋星座ピンポイント狙い撃ち**

```
♒水瓶座で「運気の波」が気になり始めた人以外は、読まなくていい。
（スコア39.9）
```

**構造を解剖すると：**

1. **星座絵文字 ＋ 星座名** → 「自分のことだ」と即座に認識させる
2. **「〜な人以外は読まなくていい」** → 排除することで逆に読まれ
