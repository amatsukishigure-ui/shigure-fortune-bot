# ライター向けフィードバック指示書
**アカウント：占術家 時雨 / 次バッチ用**

## 1. 積極的に使うべきパターン・テーマ

**【パターン】**

- **`kotodama_rank`（スコア73.2）**
　→ アカウント全体で最高スコア。「ランキング形式」＋「言霊・気」の組み合わせが時雨の世界観と相性抜群。必ず毎バッチ複数本含めること。
　→ 「お盆明け」「今週」など**時事・季節性**を絡めると特にスコアが高い傾向あり。

- **`zodiac_target`（直近最高41.8）**
　→ 星座を絞り込み＋具体的な悩み（金運・収入）で刺さる。ターゲットを狭めるほど共感が深くなる。毎バッチ3〜4本は入れる。

- **`ichi_gon`（スコア28.7、直近33.7）**
　→ 星座別の「一言で核心をつく」型。水瓶座投稿（33.7）のように**悩みの言語化→原因の意外な指摘**の流れが効く。

- **`harm_revelation`（スコア38.0）**
　→ 「有料鑑定でしか話さないことを…」系の希少性・暴露演出。定期的に投入する。

**【テーマ】**

- **「吉方位・風水 / 金運アップの吉方位」（スコア325.8）**
　→ ダントツ1位。毎バッチ必ず複数本確保。

- **「転機のサイン / 転換点を龍脈命術で見ると」（スコア157.1）**
　→ 2位。「動けない自分」への共感から入る構成が有効。

- **「鑑定エピソード / 人生の転機になった鑑定」（スコア80.0）**
　→ 実績・信頼構築に直結。1バッチ1〜2本は入れる。

## 2. 控えるべきパターン・テーマ

**【テーマ】**

- **「季節・天文と方位 / 春分・秋分と方位」（スコア3.9）**
　→ 直近でも最低スコア（3.9）。概念説明が重くなりがちで離脱を招く。完全に外すか、別パターン（例：`zodiac_target`）に乗せてのみ使う。

- **「星座占い / 来週の運気予報」（スコア5.1）**
　→ 汎用占いアカウントと差別化できない。「龍脈命術」の独自性が薄れる。使うなら必ず吉方位・風水要素をセットで入れること。

- **「転機のサイン / 動けない本当の理由」（スコア5.9）**
　→ テーマ自体は良いが現状の型では刺さっていない。`harm_revelation`や`ichi_gon`パターンに乗せて再挑戦するなら可。単体では使わない。

**【パターン】**

- **`caligula`（直近3.9）**
　→ 「〜以外は読まないで」系。時雨の静かで確信ある口調と若干ミスマッチ
